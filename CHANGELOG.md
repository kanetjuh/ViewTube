# Changelog

## Unreleased

### Added
- Modern YouTube TV-inspired home interface
- Compact persistent navigation rail
- Expandable sidebar navigation
- Account profile integration in the top navigation
- Modern microphone and search bar layout
- White rounded focus outline for selected videos
- YouTube-style video title and metadata layout
- Support for metadata badges such as 4K and CC
- Translucent collapsed navigation rail
- Full navigation labels when the sidebar is expanded

### Changed
- Reworked SmartTube's original Leanback video card presentation
- Improved horizontal video row navigation and focus alignment
- Updated spacing and sizing for TV displays
- Redesigned navigation icon layout
- Removed legacy card backgrounds, shadows and excessive focus scaling
- Improved sidebar/content interaction when browsing horizontally

### Fixed
- Navigation icons being clipped by the collapsed sidebar
- Duplicate sidebar background layers
- Incorrect account/sidebar horizontal alignment
- Video cards partially scrolling underneath the navigation rail
- Inconsistent card spacing while focused
- Metadata/title containers not matching thumbnail width
